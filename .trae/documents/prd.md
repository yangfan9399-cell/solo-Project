# 入境动物隔离观察与放行系统 - 产品需求文档

## 1. 产品概述

入境动物隔离观察与放行系统是一个专业的检疫管理平台，用于管理入境动物的隔离检疫全流程。系统支持检疫员登记批次、隔离场人员记录观察、兽医复核健康状态、监管负责人做出放行决策，确保入境动物符合检疫标准，保障生物安全。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 检疫员 | 系统分配账号 | 登记入境批次、上传证明材料、查看所有批次状态 |
| 隔离场人员 | 系统分配账号 | 填写观察记录、记录饲养情况、上报异常症状 |
| 兽医 | 系统分配账号 | 复核健康状态、签署检疫意见、标记异常情况 |
| 监管负责人 | 系统分配账号 | 审批放行决定、延长隔离、退运处理、查看统计报表 |

### 2.2 功能模块

1. **批次管理页面**: 批次列表、搜索筛选、状态标签、快速操作
2. **批次详情页面**: 动物信息、证明材料、观察记录、历史节点、放行决策
3. **观察记录页面**: 日常观察表单、异常上报、饲养记录
4. **统计报表页面**: 按来源国、动物类型、异常原因、隔离天数聚合统计

## 3. 核心流程

### 3.1 批次登记流程

检疫员在入境口岸登记动物批次信息，上传疫苗证明、健康证明等必要材料。系统自动分配隔离场，生成唯一批次号，批次状态初始化为"待登记"。

### 3.2 隔离观察流程

隔离场人员每日填写观察记录，包括体温、食欲、精神状态、排泄情况等。发现异常时立即上报，系统自动通知兽医和监管负责人。饲养记录必须每日填写，漏填将影响放行审批。

### 3.3 复核审批流程

兽医定期复核动物健康状态，签署检疫意见。监管负责人根据观察记录、兽医意见、证明材料完整性做出最终决定：
- **放行**: 所有材料齐全、观察正常、兽医同意
- **延长隔离**: 发现轻微异常需继续观察
- **退运**: 严重健康问题或证明材料缺失

### 3.4 疫苗证明缺失阻断

系统自动检测疫苗证明是否上传。若缺失，放行按钮自动禁用，显示红色警告提示，监管负责人无法执行放行操作。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深蓝色 (#1e3a5f) 代表专业与信任，搭配琥珀色 (#f59e0b) 作为警示强调色
- **辅助色**: 翠绿色 (#10b981) 表示正常状态，珊瑚红 (#ef4444) 表示异常/阻断状态
- **按钮风格**: 圆角矩形按钮，主要操作使用填充样式，次要操作使用描边样式
- **字体**: 标题使用思源黑体，正文使用系统默认无衬线字体
- **布局**: 卡片式布局，顶部导航栏，左侧功能菜单
- **图标**: 使用 Heroicons 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 批次管理 | 批次列表卡片 | 白色背景卡片，圆角8px，阴影效果，状态标签使用不同颜色区分 |
| 批次管理 | 筛选器 | 下拉选择框，支持多选，实时筛选 |
| 批次管理 | 搜索框 | 圆角输入框，带搜索图标，支持回车搜索 |
| 批次详情 | 信息卡片网格 | 三列网格布局，每个卡片展示一类信息 |
| 批次详情 | 时间线组件 | 垂直时间线，左侧日期，右侧内容，不同节点使用不同图标 |
| 批次详情 | 文件上传区 | 虚线边框拖拽区域，支持多文件上传，显示文件列表 |
| 批次详情 | 决策按钮组 | 三个大按钮横向排列，放行(绿)、延长(橙)、退运(红) |
| 观察记录 | 表单布局 | 两列表单，标签左对齐，输入框宽度自适应 |
| 观察记录 | 异常标记 | 红色边框高亮，闪烁动画提示紧急 |
| 统计报表 | 图表区域 | 柱状图、饼图、折线图，使用 Chart.js 渲染 |
| 统计报表 | 数据表格 | 斑马纹表格，支持排序，分页显示 |

### 4.3 响应式设计

采用桌面优先设计，主要针对大屏幕办公环境优化。平板设备采用两列布局，移动端采用单列堆叠布局，关键操作按钮保持可点击区域足够大。

### 4.4 交互细节

- **状态切换动画**: 批次状态变更时使用平滑过渡动画
- **表单验证反馈**: 实时验证，错误提示显示在输入框下方
- **加载状态**: 数据加载时显示骨架屏或旋转加载器
- **操作确认**: 关键操作（放行、退运）弹出确认对话框
- **成功提示**: 操作成功后显示绿色 Toast 提示，3秒后自动消失

## 5. 预置样本数据

系统预置四类典型样本数据，用于演示和测试：

1. **正常放行样本**: 所有材料齐全，观察记录完整，兽医同意放行
2. **疫苗证明缺失样本**: 缺少疫苗证明文件，放行按钮禁用，显示红色警告
3. **观察异常样本**: 观察记录中发现异常症状，需要兽医复核
4. **饲养记录漏填样本**: 部分日期缺少饲养记录，影响放行审批
