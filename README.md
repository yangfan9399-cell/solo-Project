# 旧船舶罗经自差校正台账系统

## 项目简介

专业的船舶磁罗经自差校正台账管理全栈工具，严格遵循 SOLAS 公约 Ch.V Reg.19 / IMO A.382(X) 标准设计，适用于海事机构、船级社、航运公司的罗经校正作业管理。

## 功能模块

- 📊 **自差台账工作台** - 总览统计、多条件筛选、异常高亮、关键字检索
- ⚓ **船舶档案库** - 船舶信息与罗经配置管理
- ➕ **新建校正记录** - 24 点全航向录入，实时预览自差曲线图
- 🧭 **校正详情页** - 船舶信息 + 极坐标自差曲线 + 数据表格 + 校正器配置 + 状态流转
- 📐 **校正使用表** - 8 主航向校正值 + 适用范围
- 📜 **版本历史** - 创建 / 提交 / 复核 / 批准 / 归档完整操作链路
- ⚠️ **异常数据中心** - 超差 / 缺测 / 跳变 / 曲线不连续自动检测
- 📄 **导出与打印** - HTML 正式报告 (A4) + CSV 数据 + 浏览器直接打印

## 技术栈

- **框架**: Remix 2 + React 18 + TypeScript
- **数据库**: SQLite (better-sqlite3，项目内独立文件)
- **可视化**: 原生 SVG 自差闭合曲线图
- **零全局依赖**: 所有命令封装为项目 npm 脚本

## 快速开始

```bash
# 一键初始化（安装依赖 + 创建数据库 + 插入示例数据）
npm run setup

# 启动开发服务器
npm run dev

# 打开 http://localhost:3000
```

## 项目脚本

```bash
npm run dev           # 启动开发服务器
npm run build         # 构建生产版本
npm start             # 运行生产版本
npm run typecheck     # TypeScript 类型检查
npm run db:init       # 仅创建数据库和表结构
npm run db:seed       # 仅插入示例种子数据
npm run db:reset      # 完全重置数据库（删除→重建→种数据）
npm run setup         # 完整初始化流程
```

## 数据文件

- 数据库位置: `data/compass-ledger.db`
- 首次运行 `npm run db:init` 自动创建 SQLite 文件
- 示例数据包含 5 艘真实船型档案和 10 份校正记录
