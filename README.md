# 管风琴音栓组合记忆游戏

一款通过记忆管风琴音栓组合来训练音乐耳朵和记忆力的全栈游戏。

## 技术栈

- **前端框架**: Qwik City (基于 Qwik 的全栈框架)
- **语言**: TypeScript
- **持久化**: JSON 文件存储 (轻量方案，无需编译)
- **音频**: Web Audio API 模拟管风琴音色

## 游戏玩法

1. **听辨音色**: 播放目标音栓组合的音色，仔细聆听其特点
2. **选择音栓**: 根据记忆，在音栓面板上选择你认为正确的组合
3. **验证得分**: 提交答案，系统计算得分，错误会记录到错题本

## 核心功能

- 🎵 **音栓组合**: 16种不同类型的音栓，包括主音、笛音、弦乐、簧音、混合音
- 🎹 **短句听辨**: 每关有独特的音乐短句，帮助你记忆音色特点
- 🔊 **音色复现**: 使用 Web Audio API 真实模拟管风琴音色
- 📚 **错题本**: 自动记录答错的题目，方便复习巩固
- 🔥 **每日连胜**: 连续打卡获得额外奖励，保持学习动力
- ⭐ **评分系统**: 后端计算得分，包括正确率、时间奖励、难度加成
- 📊 **玩家档案**: 记录总分、最高关卡、总场次等数据
- 🎯 **关卡系统**: 8个难度递进的关卡，从入门到大师级
- 📋 **操作历史**: 记录每一步操作，支持回溯
- 🏆 **成就系统**: 多种成就等你解锁

## 评分规则

- 基础分: 每个正确音栓 20 分
- 漏选扣分: 每个漏选音栓扣 8 分
- 多选扣分: 每个多余音栓扣 10 分
- 时间奖励: 剩余时间越多，奖励越高 (最高 30%)
- 难度加成: 难度越高，分数倍率越高 (最高 1.6x)
- 提示惩罚: 使用提示扣 40% 分数

## 数据存储

所有游戏数据存储在 `data/game-data.json` 文件中，包括：
- 玩家档案
- 游戏局次记录
- 错题记录
- 每日连胜记录
- 操作历史记录
