# 🚇 ULogistics - 城市地下物流管道调压游戏

一款基于 SvelteKit + TypeScript 开发的物流管道模拟游戏。玩家通过调节阀门气压、控制分拣节点，将胶囊包裹准时送达目的地。

## 🎮 游戏特色

- **🌡️ 气压调节** - 精确控制每个阀门的气压，决定胶囊包裹的运行速度
- **🔀 分拣控制** - 在关键节点切换分拣方向，将包裹送往正确目的地
- **💊 胶囊物流** - 监控每个胶囊包裹的实时状态，优先处理紧急物资
- **⚠️ 异常处理** - 应对管道泄漏、压力骤升、设备故障等突发情况
- **⏪ 操作回溯** - 每一步操作都被记录，可随时撤销错误操作
- **🏆 后端计分** - 最终分数由后端根据完整操作历史重新计算，确保公平公正

## 🛠️ 技术栈

- **前端**: Svelte 4 + TypeScript
- **框架**: SvelteKit 2
- **构建工具**: Vite 5
- **存储**: LocalStorage（本地持久化）
- **样式**: 原生 CSS（无外部依赖）

## 🎯 游戏玩法

1. **创建玩家档案** - 首次进入游戏时输入你的调度员代号
2. **选择关卡** - 从简单到困难，共有3个精心设计的关卡
3. **调节阀门** - 使用滑块调节每个阀门的气压，控制胶囊速度
4. **切换分拣** - 点击分拣节点切换方向，确保包裹送往正确目的地
5. **处理异常** - 及时处理管道异常，获得额外分数奖励
6. **完成目标** - 在时间限制内送达足够数量的包裹即可通关
7. **查看结算** - 游戏结束后查看详细的分数明细，后端会重新计算最终分数

## 📊 评分系统

### 评级标准

| 评级 | 分数要求（相对于最低分） |
|------|--------------------------|
| S    | ≥ 200%                   |
| A    | ≥ 170%                   |
| B    | ≥ 140%                   |
| C    | ≥ 110%                   |
| D    | ≥ 100%                   |
| F    | < 100% 或失败            |

### 分数构成

- **基础送达分** - 每个包裹成功送达获得的分数
- **准时奖励** - 包裹在限时内送达的额外奖励
- **优先级奖励** - 紧急包裹送达的额外奖励
- **异常处理奖励** - 及时处理管道异常的奖励
- **时间奖励** - 提前完成关卡的时间奖励
- **效率奖励** - 操作精简的效率奖励
- **延迟扣分** - 包裹延迟送达的扣分
- **丢失扣分** - 包裹丢失的扣分

## 💾 数据存储

所有游戏数据均存储在浏览器 LocalStorage 中，包括：

- 玩家档案（名称、总积分、游戏统计）
- 关卡数据（配置、最高分、最佳评级）
- 游戏记录（每局游戏的详细结果）
- 操作历史（用于撤销和分数重算）

## 🔧 API 接口

### 玩家相关

- `GET /api/player` - 获取玩家信息
- `POST /api/player` - 创建/更新玩家
- `PATCH /api/player` - 部分更新玩家信息

### 关卡相关

- `GET /api/levels` - 获取所有关卡
- `GET /api/levels/:id` - 获取指定关卡

### 游戏相关

- `POST /api/game/start` - 开始新游戏
- `GET /api/game/:id` - 获取游戏状态
- `PATCH /api/game/:id` - 更新游戏状态
- `POST /api/game/:id/undo` - 撤销操作
- `POST /api/game/:id/recalculate` - 后端重新计算分数

### 历史记录

- `GET /api/history` - 获取游戏历史记录
- `GET /api/replay/:gameId` - 获取回放数据

### 种子数据

- `GET /api/seed` - 获取种子数据信息
- `POST /api/seed` - 初始化/重置种子数据

## 🎨 设计特点

- **无外部样式依赖** - 全部使用原生 CSS 实现
- **响应式设计** - 适配桌面和移动设备
- **深色主题** - 采用深色配色，降低视觉疲劳
- **流畅动画** - 使用 CSS 动画和 requestAnimationFrame 实现
- **SVG 渲染** - 使用 SVG 绘制游戏场景，确保矢量清晰

## 📝 开发说明

- 项目采用纯客户端架构，所有数据存储在本地
- 后端 API 由 SvelteKit 提供，运行在浏览器环境中
- 游戏引擎使用 requestAnimationFrame 实现 60fps 游戏循环
- 分数最终由后端根据操作历史重新计算，防止前端作弊
