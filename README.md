# 地铁换乘迷宫限时游戏

一个基于 SvelteKit + TypeScript 的全栈策略游戏，玩家需要在动态变化的地铁网络中规划最优路线，躲避随机事件，赶在末班车前到达目的地。

## 游戏特性

- 🗺️ **动态换乘图** - 20个站点，6条线路，复杂的换乘网络
- ⚠️ **随机事件系统** - 扶梯停运、封站、线路延误
- ⏱️ **限时挑战** - 末班车倒计时，时间紧迫
- 🔄 **可恢复操作历史** - 随时回退到之前的步骤
- ⭐ **后端验证评分** - 分数由服务端重新计算，防作弊
- 👤 **玩家档案** - 本地保存，记录通关进度和最佳分数
- 📊 **5个精心设计的关卡** - 从简单到困难逐步挑战

## 技术栈

- **前端**: SvelteKit 2 + TypeScript + 原生 SVG 地图渲染
- **后端**: SvelteKit Server API Routes
- **存储**: 轻量 JSON 文件存储（无需数据库服务）
- **算法**: A* 寻路 + 动态事件系统 + 多维度评分引擎

## 玩法说明

1. **创建玩家档案** - 首次游戏需要创建本地玩家身份
2. **选择关卡** - 5个难度递增的关卡
3. **开始游戏** - 选择上车站点和线路
4. **规划路线** - 根据地图和事件提示选择最优路线
   - 点击地图上高亮的相邻站点快速移动
   - 在换乘站切换线路（消耗3秒）
   - 必要时可以等待事件结束
5. **使用回退功能** - 随时点击左侧历史记录步骤进行回退
6. **抵达终点** - 到达目标站点后点击"提交路线"获得评分

## 评分规则（服务端计算）

| 项目 | 说明 |
|------|------|
| 基础分 | 根据难度: 简单1000 / 中等2000 / 困难3500 |
| 时间奖励 | 快于基准时间获得最高500分 |
| 换乘奖励 | 少于基准换乘次数每次+200分，超出每次-100分 |
| 事件惩罚 | 等待时间每秒-15分，绕路每次-50分 |
