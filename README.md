# 口腔门诊器械消毒追溯与使用登记系统

面向消毒护士、诊室医生和院感管理员的器械消毒全流程追溯系统。

## 技术栈

- **后端**: Django 5.1 + SQLite
- **前端**: Tailwind CSS (CDN) + HTMX
- **Python**: 3.12+

## 快速启动

```bash
# 1. 创建虚拟环境并安装依赖
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. 执行数据库迁移
python manage.py migrate

# 3. 加载示例数据
python manage.py load_sample_data

# 4. 创建管理员账号（可选）
python manage.py createsuperuser

# 5. 启动开发服务器
python manage.py runserver
```

访问 http://127.0.0.1:8000/ 即可使用系统。

## 业务流程

系统覆盖器械包从建档到报废的完整生命周期：

```
建档(在库) → 领取使用(使用中) → 送洗(清洗中) → 送灭菌(灭菌中) → 待放行 → 放行入库(在库)
                                                                          ↑
                                                        完成一个循环 ────────┘

异常流程:
在库 → 已过期 → 发起召回(已召回) → 重新清洗 → ...
```

### 核心环节

| 环节 | 角色 | 说明 |
|------|------|------|
| 器械包建档 | 消毒护士 | 登记器械包编号、名称、分类、内容物、所属诊室 |
| 回收清洗 | 消毒护士 | 记录清洗方式（手工/超声/机械）、清洗剂、清洗结果 |
| 灭菌批次 | 消毒护士 | 创建灭菌批次，关联器械包，记录温度/压力/时长，录入三项监测结果 |
| 放行审核 | 院感管理员 | 核查包装完好性、指示卡变色、标识清晰、封口完好，审核放行或不通过 |
| 诊疗使用 | 诊室医生 | 登记患者信息、诊疗项目、使用时间，归还后自动流转至清洗中 |
| 过期召回 | 院感管理员 | 系统自动检测过期器械，支持手动发起召回，处理召回或销毁 |
| 院感抽查 | 院感管理员 | 对器械包、灭菌批次或环境进行抽查，记录发现问题和纠正措施 |

## 功能页面

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页仪表盘 | `/` | 统计概览、最近使用、过期预警、状态分布 |
| 器械包列表 | `/instruments/` | 搜索、状态/分类筛选、新建 |
| 器械包详情 | `/instruments/<uuid>/` | 完整追溯链、状态流转、关联记录 |
| 清洗记录 | `/cleanings/` | 清洗记录列表、新建、结果筛选 |
| 灭菌看板 | `/batches/` | 三列看板（待检测/合格/不合格） |
| 灭菌详情 | `/batches/<id>/` | 三项监测结果录入、器械包列表、审核记录 |
| 放行审核 | `/audits/` | 审核列表、新建审核、检查项勾选 |
| 诊疗使用 | `/usages/` | 使用登记、归还操作、诊室筛选 |
| 过期召回 | `/recalls/` | 召回列表、发起召回、处理召回 |
| 院感抽查 | `/inspections/` | 抽查列表、新建抽查、类型筛选 |
| 过期检查 | `/check-expiry/` | 一键检查并自动标记过期器械 |

## 数据模型

- **InstrumentPackage** - 器械包：编号、名称、分类、状态、诊室、过期时间
- **CleaningRecord** - 清洗记录：清洗方式、清洗剂、清洗人、结果
- **SterilizationBatch** - 灭菌批次：批次号、灭菌方式、温压参数、三项监测结果
- **ReleaseAudit** - 放行审核：四项检查（包装/指示卡/标识/封口）、审核结果
- **ClinicalUsage** - 诊疗使用：患者信息、医生、诊疗项目、归还时间
- **ExpiryRecall** - 过期召回：召回原因、发起人、处理状态
- **InfectionInspection** - 院感抽查：抽查类型、发现问题、纠正措施
